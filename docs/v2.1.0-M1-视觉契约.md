3. **自定义表情**：**不纳入** v2.1；只做台词库与既有预置表情的气泡增强。
4. **战绩明细**：**允许**新增本地存储键 `uno:records`（只写本地，不进协议）。
5. **出牌飞行动画**：**跟随现有动画开关**（`uno:settings.animation`，默认开启）。

## 2. M2 契约：对手卡背 N 张分档 + 数量变化动效

### 2.1 分档规则（替换 M13 的「封顶 5 张」语义）

现有实现：`players.js` `OPPONENT_HAND_MAX = 5`，`renderOpponentHand` 渲染 `min(5, handCount)` 张。**渲染张数规则不变**（1~5 张逐张，0 张不显示），新增溢出表达：

| handCount | 卡背张数 | 新增视觉 |
| --- | --- | --- |
| 0 | 0（不渲染） | 不变 |
| 1~5 | 逐张 | 不变 |
| 6~9 | 5 张 | `.opponent-hand[data-overflow]` + 溢出徽标 `.opponent-hand-overflow` 显示「+N」（N = handCount − 5，荧光绿小字） |
| ≥10 | 5 张 | 徽标「+N」且 `.opponent-hand.is-full`（卡背间距收密 + 徽标亮度提升） |

- `data-overflow` 取值 `0`（无徽标）或正整数；`.opponent-hand-overflow` 与卡背同为 `aria-hidden="true"` 装饰层。
- 精确牌数仍只由座位文本/`aria-label`（「XX，N 张牌」）提供，徽标不是数据来源。
- 420 宽度维持「可隐藏卡背层、必须保留精确牌数」；溢出徽标随卡背层一起隐藏。

### 2.2 M13-04 数量变化反馈

- 触发：座位节点 `data-hand-count` 值发生变化时**一次性**播放（diff 驱动，禁止 render 重播）。
- 增加：最顶卡背 240ms 推入（scale 0.8→1 + translate）；减少：顶卡背 240ms 弹出淡出后移除。
- 时长走 `--v2-dur-fast`/`--v2-dur-base` token；`prefers-reduced-motion` 或 `animation: false` 时无动画，直接切换张数（静态降级）。
- 当前回合座位维持 M13-04 原约定「仅静态上移」，不加脉冲。

### 2.3 新增 DOM/属性

| 锚点 | 说明 |
| --- | --- |
| `.opponent-hand[data-overflow]` | 溢出张数（数字字符串，"0" 表示无溢出） |
| `.opponent-hand.is-full` | handCount ≥10 满堆样式 |
| `.opponent-hand-overflow` | 溢出徽标节点，`aria-hidden="true"` |

既有 `.opponent-hand`、`.opponent-hand-card`、`data-hand-count`、`data-visible`、`data-layout="fan"` 全部不变。

## 3. M3 契约：牌面动效升级

### 3.1 触发与来源（事件队列唯一驱动）

| 动效 | 触发事件 | 视觉 |
| --- | --- | --- |
| 出牌飞行 | `PLAY` 事件消费时 | 手牌原位克隆体（`.fly-card`）飞向 `#discard-pile` 顶牌位，约 360ms，落位后克隆体移除 |
| 开局发牌 | 对局进入 `await-play` 首次 render | 按座位顺序从牌堆向各座位短滑入，单张约 120ms、总时长上限 1.2s，一次性 |
| 摸牌反馈 | 自己 `DRAW` 且 `cards.length>0` | 新牌从牌堆方向短滑入手牌区，约 240ms |

- 复用 M6 结算飞牌（`animation/resultTransition.js`）的降级链模式：源 rect 缺失 → 静态入场。
- 降级链：`animation: false` / `prefers-reduced-motion` / 源缺失 / 联机补发乱序 → 直接落位，无飞行。
- 联机事件补发或重连后**不重播**历史动效；动画期间沿用现有输入锁（`aria-busy`）。
- 只用 transform/opacity；完成后清理克隆节点与临时 class；`animationSpeed` 缩放全局时长。

## 4. M4 契约：台词库（M6-03）

- 新增 `apps/web/js/ui/lines.js`：纯前端内容表，键 = 事件类别（`play` / `draw-heavy` / `wild4` / `challenge` / `catch-uno` / `uno` / `win` / `lose`），值为台词数组；同一事件 30s 内不重复同句。
- 开关**复用现有 `aiChatter`**（`uno:settings`，默认 true），设置页现有「AI 台词」控件语义不变；关闭后零台词。
- 渲染走现有 `#speech-layer` 气泡 + `clearPlayerLine` TTL 机制；台词只是替换气泡**文本来源**，TTL、aria、清理机制零改动。
- 台词为低频装饰（信息优先级第 4 层），不新增协议字段；单机/联机行为一致（联机 AI 座位同样只消费公开事件）。

## 5. M5 契约：本地战绩页（M6-04）

- **入口复用现有**：大厅 `data-open-dialog="stats"`「战绩」按钮 → 升级现有「本地战绩」弹窗内容，不新增页面与路由（`data-screen` 体系不动）。
- **汇总**（既有数据）：对局数、获胜数（`uno:stats`，读写逻辑零改动）。
- **明细**（新键 `uno:records`）：`recordResult`（单机 `engineMode.js` 调用点）顺带追加一条 `{ at, players, rank, win }`，数组封顶 20 条、新的在前；联机对局不写战绩（与现有 `uno:stats` 边界一致）；写入失败静默忽略。
- 展示：最近对局列表（时间、人数、名次/获胜标记）；空态文案「还没有完成过对局」；读取容错（损坏数据按空数组降级）。
- 弹窗仍为现有 dialog 体系（可键盘关闭、`source` 焦点归还）；420 宽度单列不溢出。
- 红线不变：无分数；`uno:stats` 既有键不迁移不改键。
