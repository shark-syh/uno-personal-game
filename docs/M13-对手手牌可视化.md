# M13 对手手牌可视化（MVP 已完成）

> **状态：✅ MVP 已完成（2026-10-23）**，作为 v2.0.0 的 V2-01 交付。
> 目标：在对手座位框左下角显示 1~5 张缩小卡背，按手牌数呈现；右上角「上一张出牌」保留。
> 关联：[`开发进度.md`](./开发进度.md)、[`v2.0.0-UI开发计划.md`](./v2.0.0-UI开发计划.md)、[`v1-开发归档.md`](./v1-开发归档.md)。

## 1. 范围

**MVP**

- 只读 `view.players[*].handCount`，不改 GameView、服务端或 WebSocket 协议。
- 映射：`0 → 不显示`、`1~5 → 对应张数`、`≥6 → 显示 5 张`；精确数量继续用「N 张」。
- 卡背 22×33px，每张旋转 5°，步进 3px，扇形叠放；当前回合静态上移约 2px。
- 1024 / 760 / 420 三档响应式；`prefers-reduced-motion` 与关闭动画下保持静态。
- 卡背 `aria-hidden="true"`；对手 `aria-label` 继续提供准确牌数。

**非目标**

- 不展示牌面，不改变规则或手牌数量。
- 不替换 `lastPlayed`，不重做对手框布局。
- 不做完整 N 张、皮肤、设置项；这些留给 M13-06。

## 2. 视觉规格

| `handCount` | 可见卡背 | 说明 |
| --- | --- | --- |
| 0 | 0 | 不显示 |
| 1 | 1 | UNO 时可轻微强调 |
| 2~4 | 对应张数 | 小角度展开 |
| ≥5 | 5 | 封顶；精确数字仍看文本 |

- 位置：左下角、略微超出框底；不覆盖名字/牌数/`lastPlayed`/UNO；`pointer-events: none`。
- 尺寸：`--oh-card-w: 22px`、`--oh-card-h: 33px`、`--oh-step: 3px`、`--oh-rotate: 5deg`、`--oh-offset-y: -2px`。
- 760：18×27，仍最多 5 张；420：隐藏卡背，保留「N 张」。
- 卡背用 `assets/card-back.svg` 背景，不为每张卡生成 `<img>` 或 alt。

## 3. DOM 契约

```html
<article class="opponent" data-seat="1" data-hand-count="3">
  ...
  <div class="opponent-hand" data-visible="3" data-layout="fan" aria-hidden="true">
    <span class="opponent-hand-card" style="--oh-i: 0; --oh-center: 1"></span>
    <span class="opponent-hand-card" style="--oh-i: 1; --oh-center: 1"></span>
    <span class="opponent-hand-card" style="--oh-i: 2; --oh-center: 1"></span>
  </div>
</article>
```

- `data-hand-count`：真实手牌数；`data-visible`：当前可见卡背数；`data-layout="fan"`：后期布局切换点。
- 类名固定 `.opponent-hand` / `.opponent-hand-card`；不要复用 `.mini-card`。
- JS 只写 `--oh-i` 与 `--oh-center`，偏移/旋转由 CSS `calc()` 计算；最大张数由 `OPPONENT_HAND_MAX` 控制。
