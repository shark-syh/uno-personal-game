# M13 对手手牌可视化（MVP 已完成）

> **状态：✅ MVP 已完成（2026-10-23）。** M13-01~M13-03、M13-05 已落地；M13-04 仅做当前回合静态强调，动效后置；M13-06 完整版仍预留。
> 目标：在对手座位框内显示缩小版卡背，按手牌数量呈现，模拟对手拿牌；默认保留右上角「上一张出牌」。
> 关联：[`开发计划.md`](./开发计划.md) §11、[`开发进度.md`](./开发进度.md) §6、[`交接文档.md`](./交接文档.md)。

## 1. 背景与目标

- 当前对手框右上角的小牌是 `lastPlayed`（上一张出牌），不是手牌；手牌数量只以「N 张」文字显示。
- M13 增加一个独立的「对手手牌堆」：卡背悬浮在角色框前方，按 `handCount` 决定可见张数。
- **不改服务端、不改协议、不改 GameView**：`player.handCount` 已存在，`renderPlayers()` 每次视图更新都会重建座位框。
- 成功标准：玩家一眼能看出对手大约还有多少张牌，同时不遮挡名字、UNO、上一张出牌，不泄露任何牌面。

## 2. 范围

### 2.1 本期 MVP

- 对手框**左下角**悬浮 1~5 张卡背，扇形叠放；右上角 `lastPlayed` 保留。
- 张数映射：`0 → 不显示`，`1~5 → 对应张数`，`≥6 → 显示 5 张`；精确数量继续用现有「N 张」文字。
- 卡背尺寸 **22×33px**，最大 5 张；每张旋转 `5°`，5 张约 `-10° ~ 10°`。
- 支持 4 人 / 10 人布局，1024、760、420 三档宽度。
- 桌面/浏览器、单机/联机共用；`prefers-reduced-motion` 与「关闭动画」下保持静态。
- 卡背仅作装饰，`aria-hidden="true"`；对手 `aria-label` 继续提供准确牌数。

### 2.2 后期完整版（预留，不在本期实现）

- 右侧版本：把卡背堆移到右侧，或将 `lastPlayed` 改成「刚出 X」文字角标。
- 完整 N 张模式：手牌有几张就显示几张（仅在性能/布局验证通过后启用）。
- 更细的动画：摸牌/出牌时卡背数量变化脉冲、当前回合轻微浮动、UNO 单张强调。
- 皮肤/主题：自定义卡背、不同座位朝向、桌面版与移动端不同密度。
- 可选设置项：显示密度、是否显示上一张出牌、是否启用动效。

### 2.3 非目标

- 不展示对手手牌牌面，不改变手牌数量或规则。
- 不引入服务端字段、不新增 WebSocket 消息。
- 不在本期重做整个对手框布局，不替换现有 `lastPlayed`。
- 不做完整 N 张、皮肤、设置项；这些留给后期。

## 3. 视觉规格

### 3.1 位置

MVP 使用**左下角、略微超出框底**的悬浮卡背堆：

```
┌──────────────────┐
│ (头像)  老王   [上一张]
│         3 张      │
│ [▧▧▧]            │
└──────────────────┘
```

- 右上角：`lastPlayed` 保持现状。
- 右下角：UNO 状态标签保持现状。
- 左下角：卡背扇形，覆盖头像下缘，不进入名字/张数文本区域。
- 卡背堆 `pointer-events: none`，不阻塞座位框和表情气泡。

### 3.2 尺寸与张数

| `handCount` | 可见卡背 | 说明 |
| --- | --- | --- |
| 0 | 0 | 不显示 |
| 1 | 1 | UNO 状态可额外做轻微强调 |
| 2 | 2 | 两张小角度展开 |
| 3 | 3 | 默认扇形 |
| 4 | 4 | 角度略增 |
| ≥5 | 5 | 封顶；精确数字仍看「N 张」 |

- 卡背：`22×33px`，圆角 `4px`，白色细边，阴影 `0 4px 6px #0007`。
- 叠放步进 `3px`，每张旋转 `5°`，围绕底部中心展开。
- 5 张时布局宽度 `34px`，旋转后视觉宽度约 `46px`；已实测不压名字/张数，仍在座位框左下角安全区域内。

### 3.3 状态

- **当前回合**：卡背堆整体上移约 `1~2px` 或提高亮度；不做持续漂浮动画。
- **UNO**：1 张卡背可加一层淡黄色外发光；不改变 UNO 状态标签。
- **手牌变化**：MVP 只重渲染，不做动画；M13-04 再考虑脉冲。
- **动画关闭 / reduced-motion**：所有新增动效禁用，静态卡背保留。

### 3.4 响应式与可访问性

- `<=760px`：对手框变为网格布局，卡背缩为 `18×27px`，仍最多 5 张；优先保证不压文字。
- `<=420px`：隐藏卡背堆，继续显示「N 张」；与现有 `.mini-card` 的隐藏策略一致。
- 卡背堆 `aria-hidden="true"`；不要给每张卡背加「抽牌堆」等重复 alt 文本。
- 对手 `aria-label` 已包含「N 张牌」，保持不变。

## 4. 技术方案

### 4.1 数据与渲染

- 数据源只用 `view.players[*].handCount`、`saidUno`、`seat`、`view.currentSeat`、`viewer`。
- `renderPlayers()` 中新增一个辅助函数，按 `handCount` 生成卡背堆；与 `lastPlayed` 的 `renderCard()` 完全分离。
- 不修改 `hand.js` 的 `cardBack()`；卡背用 CSS 背景引用 `assets/card-back.svg`，避免每个对手重复 `<img>` 和 alt。
- 不修改 `GameView`、`server`、`ws` 协议。

### 4.2 稳定 DOM 契约

```html
<article class="opponent" data-seat="1" data-hand-count="3">
  ...
  <div class="opponent-hand" data-visible="3" data-layout="fan" aria-hidden="true">
    <span class="opponent-hand-card" style="--oh-i: 0; --oh-center: 1"></span>
    <span class="opponent-hand-card" style="--oh-i: 1; --oh-center: 1"></span>
    <span class="opponent-hand-card" style="--oh-i: 2; --oh-center: 1"></span>
  </div>
</article>
```

- `data-hand-count`：真实手牌数，供后期完整版/动画/测试使用。
- `data-visible`：当前可见卡背数，避免 CSS/JS 重复计算。
- `data-layout="fan"`：为后期 `stack` / `full` / `right` 等模式预留切换点。
- 类名固定为 `.opponent-hand` / `.opponent-hand-card`；**不要复用 `.mini-card`**，避免与结算页统计语义混淆。

### 4.3 CSS 变量

在 `.opponent-hand` 或 `:root` 上预留：

```css
--oh-card-w: 22px;
--oh-card-h: 33px;
--oh-step: 3px;
--oh-rotate: 5deg;
--oh-offset-y: -2px;
```

- 卡背使用 `background: url("../assets/card-back.svg") center / 100% 100% no-repeat`。
- `position: absolute; left: 4px; bottom: -6px; z-index: 2; pointer-events: none;`
- JS 只写入每张卡的 `--oh-i` 与 `--oh-center`；横向偏移和旋转由 CSS `calc()` 计算，便于后期主题覆盖。
- 最大 5 张由 JS 常量 `OPPONENT_HAND_MAX` 控制；不建议为每个张数写一套硬编码 CSS。

## 5. 风险与取舍

| 风险 | 处理 |
| --- | --- |
| 左下角卡背覆盖头像 | 控制 22×33、最多 5 张、`bottom:-6px`；实在拥挤时改为单张+层叠阴影 |
| 右侧与 `lastPlayed`/UNO 冲突 | MVP 不放右侧；右侧方案留给 M13-06 |
| 10 人局视觉过密 | 最多 5 张；`<=760px` 缩为 18×27；`<=420px` 隐藏 |
| 每次重渲染导致动画重启 | MVP 不做持续动画；M13-04 用状态 diff 只触发一次脉冲 |
| 测试只检查座位框，漏掉卡背溢出 | 新增卡背 rect 的视口/手牌区/相邻框断言 |
| 完整 N 张性能/可读性差 | 作为 M13-06 可选模式，默认不启用 |

## 6. 后期完整版预留

- 保持 `.opponent-hand[data-layout]` 作为布局切换点；以后可增加 `fan` / `stack` / `right` / `full`。
- 保留 `data-hand-count`，后期可做「张数变化」动画、统计或调试面板。
- 卡背尺寸、步进、旋转全部走 CSS 变量，便于主题/皮肤覆盖。
- `lastPlayed` 始终独立，不把两者合并；后期若要替换，只移除/改写 `lastPlayed` 节点，不影响卡背堆。
- 若未来要做完整 N 张，先做性能和 10 人布局评估，再决定是否启用。
