## 一、V2.2 目标与范围

### 1. 目标

把三屏（大厅 / 牌桌 / 结算）从 v2.0.0 的「椭圆桌 + 圆周座位 + 悬浮手牌坞」结构，整体升级为 radical demo A 方向的「控制面板」版式。配色已在 v2.0.0 换肤完成，本版**只动结构与版式**，配色基线不变。

| 屏幕 | 现状 | v2.2 目标（A 方向） |
|---|---|---|
| 大厅 | 单列品牌 + 面板 | 两栏：左「PLAY WITH INTENT.」巨字排版 + index 项，右 setup 设置卡 |
| 牌桌 | 全宽椭圆竞技场 + 底部悬浮手牌坞 | 三栏 `102px 回合轨 \| 竞技场 \| 238px 状态栏` + 底部手牌/动作双列（文档流） |
| 结算 | 面板式总结 | 巨字「XX WINS.」+ 六格统计条 + 玩家动作条形图 + 动作构成环形图 |

### 2. 硬约束（与 v2.0.0 一致）

- 不改：`packages/game-core`、`packages/ai`、`apps/server`、`GameView`/`UiAction` 形状、WebSocket 协议、服务端脱敏边界、`js/vendor/uno-engine.js`。
- `window.UnoApp` 五个 API（render/playEvents/setActionHandler 等）与既有 DOM 锚点**只增不改**：`#hand`/`#action-bar`/`#opponents`/`#table-center`/`#draw-pile`/`#discard-pile`/`#stack-badge`/`#event-feed`/`#hint-bar`/`#turn-stamp`/`#phase-label`/`#lobby-form`/`#lobby-start`/`#room-panel`/`#result-content` 等全部保留；v2.1.0 四切片新增的锚点（卡背分档徽标、战绩页等）同样只增不改。
- 悬浮层全保留，仅校准定位基准与 z-index（沿用 `--z-*` token）：`#speech-layer`、`#challenge-reveal`、`#effect-layer`、`#dialog-root`、`#toast-region`、`#emote-picker`、`#dev-toolbar`。
- M13 对手手牌可视化、联机脱敏、视角换位、UNO 窗口时长映射（`unoTiming.js`）、飞牌结算转场等功能行为零改动，只换皮与换位。
- 验证基线只增不改：`verify:ui` 137 项（v2.1.0 完成后以其最新数为基线）、`verify:online` 32 项全部保持通过。

### N4：牌桌主体（最大阶段，必要时拆 N4a 结构 / N4b 数据接线）

- **右 right-rail（新增，238px）**：两张 status-card——「CURRENT PRESSURE」（当前玩家大数字 + 你的手牌数 / 可出牌数荧光高亮 / 牌堆剩余）与「RECENT EVENTS」（上一手牌 / 上一位玩家 / 状态）。数据全部取自现有 hud/table 状态，不新增请求。

### N6：响应式 / 无障碍 / 性能收口

- 断点沿用现有 W1~W6 体系并移植 demo 规则：≤1080px 隐藏 right-rail、三栏变两栏；≤760px 改文档流（phase-rail 横排、各区块依次堆叠、action-stack 横向网格）；≤420px 沿用极窄降级；`max-height:820px` 矮屏复查。
