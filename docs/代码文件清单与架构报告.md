## 1. 架构总览

```
┌──────────────────────────── apps/desktop（Electron 壳，可选）────────────────────────────┐
│ main.ts → environment.ts → 内嵌 apps/server → BrowserWindow 加载 apps/web                  │
│ secretStore(DPAPI Key) · discovery(UDP 41234 局域网发现) · preload/ipc                    │
└───────────────────────────────────────┬─────────────────────────────────────────────────┘
                                        │ HTTP / WebSocket
┌───────────────────────── apps/server（Node + Express + ws）───────────────────────────────┐
│ index.ts → server.ts → app.ts ─┬─ static.ts（托管 apps/web）                             │
│                                ├─ routes/health.ts（/api/health：版本、lanUrls、AI 状态） │
│                                └─ routes/ai.ts → prompts/ai-decide.ts → zhipu.ts          │
│ net/wsServer.ts → net/rooms.ts（房间/座位/权威裁决）+ net/aiDriver.ts（AI 代打）           │
│ net/protocol.ts（消息校验）· net/lan.ts（局域网地址）· ai-key.ts（Key 来源）               │
└───────────────────────────────────────┬─────────────────────────────────────────────────┘
                                        │ 按座位脱敏的 GameView / 事件
┌──────────────────────────────── apps/web（零构建 ES Modules）───────────────────────────┐
│ app.js → engine/engineMode.js（单机权威循环） | net/onlineMode.js（联机客户端）            │
│          ui/render.js → lobby / table / players / hand / hud / result / dialogs          │
│          animation/queue.js + effects.js（事件动画）· audio/sfx.js（WebAudio）             │
│          state/settings · stats · viewer（视角座位）· ui/emotes.js（联机表情）              │
│ js/vendor/uno-engine.js ← esbuild 产物（game-core + ai，禁止手改）                         │
└───────────────────────────────────────┬─────────────────────────────────────────────────┘
                                        │ import
┌────────────────── packages（纯 TS，可确定性复现，无 UI/网络依赖）──────────────────────────┐
│ game-core：types/config/rng/deck/setup/legal/engine/result/public-view                    │
│ ai：types/difficulty/view/memory/features/scoring/candidates/decide/selfplay              │
└───────────────────────────────────────────────────────────────────────────────────────────┘
              ▲ 测试：各包 tests/ + apps/server/tests/（vitest） · 验收：scripts/verify-*.mjs
```

关键边界（与 docs/交接文档.md「红线」一致）：

- 规则与 AI 只在 `packages/*` 内演进；Web/服务端只消费公开视图。
- 联机信息隔离由 `public-view.ts`（按座位脱敏）+ `rooms.ts`/`wsServer.ts`（按连接广播）共同保证。
- UI 契约 `window.UnoApp` 与 DOM 锚点只增不改。
