## 推荐阅读顺序（新接手）

1. [`交接文档.md`](./交接文档.md) —— 当前状态、质量基线、红线、坑位与新对话提示词
2. [`开发约定.md`](./开发约定.md) —— 协作流程：未说「开始 Mx」不开工、四段式汇报、每模块完成即停
3. [`开发进度.md`](./开发进度.md) —— 里程碑台账、已知限制
4. [`开发计划.md`](./开发计划.md) —— 规则规格、技术架构、AI 设计、测试与运行
5. [`UI开发提示词.md`](./UI开发提示词.md) —— UI ↔ 引擎契约（字段与 DOM 锚点冻结，只增不改）
6. [`E2E测试指南.md`](./E2E测试指南.md) —— verify:ui（单机）/ verify:online（联机）的使用与扩展
