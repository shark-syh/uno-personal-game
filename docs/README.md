# 项目文档索引

> 本目录收录项目的开发文档、验收报告与 README 截图。日常使用请看根目录 [`README.md`](../README.md)；版本变更见 [`CHANGELOG.md`](../CHANGELOG.md)（当前 **v1.0.0**，2026-10-18）。

## 推荐阅读顺序（新接手开发者）

1. [`开发约定.md`](./开发约定.md) —— 协作与汇报约定（未明确说「开始 Mx」不自行开工；四段式汇报；每模块完成即停）
2. [`开发进度.md`](./开发进度.md) —— 精炼台账：里程碑状态、红线硬约定与已知限制（最新 **M0~M7**）
3. [`开发计划.md`](./开发计划.md) —— 需求、规则规格书（第 4 章）、技术架构、里程碑（第 8 章，含 **M8 本地联机**）、测试计划（第 9 章）
4. [`UI开发提示词.md`](./UI开发提示词.md) —— UI ↔ 引擎契约（字段冻结，只增不改）、视觉规范、分阶段提示词
5. [`UI验收报告.md`](./UI验收报告.md) —— UI 各阶段验收报告与已知问题
6. [`E2E测试指南.md`](./E2E测试指南.md) —— verify:ui（单机）/ verify:online（联机双客户端）验收套件的使用、CI 与扩展方法
7. [`交接文档-2026-10-19.md`](./交接文档-2026-10-19.md) —— 当前状态、红线约定、坑位与 M8 待办
