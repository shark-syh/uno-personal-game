## 推荐阅读顺序（新接手开发者）

1. [`开发约定.md`](./开发约定.md) —— 协作与汇报约定（未明确说「开始 Mx」不自行开工；四段式汇报；每模块完成即停）
2. [`开发进度.md`](./开发进度.md) —— 各模块进度与验证记录（最新为 M0~M6，第二十四~二十八节含 M5/M6 记录）
3. [`开发计划.md`](./开发计划.md) —— 需求、规则规格书（第 4 章）、技术架构、里程碑（第 8 章）、测试计划（第 9 章）
4. [`UI开发提示词.md`](./UI开发提示词.md) —— UI ↔ 引擎契约（字段冻结，只增不改）、视觉规范、分阶段提示词
5. [`UI验收报告.md`](./UI验收报告.md) —— UI 各阶段验收报告与已知问题
6. [`交接文档-2026-10-18.md`](./交接文档-2026-10-18.md) —— 当前状态、关键约定、坑位与 M7 待办
