# 暂缓计划：M12 跨网公网入口（Tailscale Funnel）

> 状态：**暂缓，不开发**（2026-10-21 起）。不排期、不写实现代码、不执行真机验证。
> 恢复条件：用户明确说「重新开始 M12」，并重新确认依赖、端口、邀请与安全加固方案。
> 配套步骤摘要见 [`M12-01-Tailscale-Funnel验证指南.md`](./M12-01-Tailscale-Funnel验证指南.md)。

## 1. 暂缓原因

- v1.3.0 的范围是本机单机、局域网联机与 Windows 桌面版。
- 公网入口会引入 Tailscale 依赖、公网暴露、限流、Origin 校验与智谱额度保护等额外工作。
- 用户当前不继续开发网络联机功能，M12-02~M12-06 不开始。

## 2. 原方案（仅存档）

**目标**

- 房主安装 Tailscale 并登录一次，开启 Funnel；UNO 桌面版开房后暴露 `https://<设备>.<tailnet>.ts.net`。
- 客人任意网络用浏览器打开固定网址，输入房间码进入；不需要 Tailscale、UNO 或注册。
- 单机、局域网、手动 `IP:端口` 保持不变；Funnel 不可用时自动回退。
- 房主关房/退出时关闭 Funnel；断线重连、`server-closing`、视图脱敏复用现有逻辑。

**非目标**：账号/排行榜/付费；Tailscale peer discovery / UDP 打洞；自建公网服务器、VPS、frp、Cloudflare Tunnel；macOS/Linux 安装包、自动更新、签名；凭据或 Key 打进安装包。

**架构**

```text
客人浏览器
  https://<设备>.<tailnet>.ts.net
        │ HTTPS / WSS
        ▼
Tailscale Funnel（公网 TLS 入口）
        │
        ▼
房主电脑 127.0.0.1:<UNO端口>
  └─ 现有 Express + ws（权威游戏状态）
```

- Funnel 仅允许 443 / 8443 / 10000；默认 443，网址不带端口。
- 页面由房主内嵌服务提供；HTTPS 下前端自动走 `wss://.../ws`。
- 游戏核心、房间码、重连 token、按座位脱敏、主机退出通知均不改。

**原模块**

| 模块 | 内容 |
| --- | --- |
| M12-01 | 验证指南（文档已完成，暂缓执行） |
| M12-02 | 桌面集成：检测 CLI/Funnel、开房启动 `tailscale funnel --bg <端口>`、关房清理、`publicUrl` 注入 |
| M12-03 | 端口与邀请：`UNO_DESKTOP_PORT`、邀请优先公网 URL、保留局域网/手动兜底 |
| M12-04 | 安全加固：限流、Origin 校验、房间密码/房主确认、`/api/health` 脱敏、保护 `/api/ai/decide` |
| M12-05 | 真机验收：双网络、10 人、长局、重连、主机退出、Tailscale 断线/恢复 |
| M12-06 | 桌面客机公网加入：`wss://` 适配；固定主机或房间目录 |

**安全边界**

- Funnel URL 是公网地址，任何拿到链接的人都能打开；6 位房间码不是强认证。
- 必须做：加入限流、人数/连接上限、WebSocket Origin 校验；建议房间密码或房主确认。
- `/api/health` 对公网不得返回完整 `lanUrls`；安装包不带 `.env`，日志不打印 Key。
- `/api/ai/decide` 会消耗房主智谱额度，公网必须加同源/房间 token/限流，或对公网禁用在线 AI。
- 只暴露 UNO 服务端口，不暴露文件系统、管理接口或 Tailscale 管理面。

**限制与风险**

- Funnel 为 Beta，有非配置带宽限制；仅 443/8443/10000、仅 TLS。
- 房主必须登录 Tailscale 并开启 MagicDNS/HTTPS/Funnel；网址依赖设备名与 tailnet 名。
- 房主电脑必须开机、联网；房间仍只在内存。
- WebSocket 兼容性与 WSS 必须真机验证；公网 URL 有扫描、枚举与额度滥用风险。

**恢复前需重新确认**：Funnel 自动还是手动启停；是否固定端口；公网 URL 与局域网地址的展示优先级；房间密码默认值；桌面客机公网加入是否要做；账号系统是否要做。

## 3. 当前替代方案

继续使用本机单机、同局域网房间码、桌面版 UDP 附近房间/手动 `IP:端口`。远程组网（ZeroTier、Tailscale、VPN）由用户自行解决，不属于本项目开发范围。
