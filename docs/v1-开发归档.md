## 4. M13 摘要

- 对手框左下角按 `handCount` 显示 1~5 张卡背；`0` 隐藏、`≥6` 封顶 5 张，精确数量仍看「N 张」。
- 卡背 22×33（760 为 18×27、420 隐藏）；`aria-hidden`，不遮挡 `lastPlayed` / UNO / 表情。

- 当前回合仅静态上移；数量变化脉冲（M13-04）与完整版（M13-06）后置。

## 6. v1 已知限制

- 智谱单次决策约 3.8s；设置页规则只对新开对局生效；`wild4Legality` 未上设置页。
- 刷新会中断单机对局；联机房间只在服务进程内存，重启即失效。
- 联机 AI 固定本地启发式，智谱在线决策未接入。
- 表情仅纯 emoji，无自定义/持久化/文字聊天。
- 启动脚本不自动提权；局域网首次可能需管理员放行防火墙。
- 主机退出通知只覆盖正常关窗；强杀/断电时客户端重连 3 次后回大厅。
- UDP 仅同网段；防火墙/AP 隔离时用手动 `IP:端口`。
- 桌面 Key 的 DPAPI 只防其他 Windows 用户；安装包未签名；真机验收未完成。
- 跨网公网联机（M11/M12）暂缓，不提供公网固定网址。
