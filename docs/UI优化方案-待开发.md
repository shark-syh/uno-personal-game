## 0. 硬性规定：所有 UI 圆角必须使用连续曲率（即刻生效）

> **例外（2026-11-07 用户追加拍板，优先级最高）**：「**数据显示的卡片不用做圆角**」。
> 对局右栏的 `.status-card`（CURRENT PRESSURE / RECENT EVENTS）与 `.rail-turn-chip`（TURN 回合标签）是纯信息面板，
> 一律 `border-radius: 0` + 1px 实线边框，**不套 squircle 遮罩**；本节只约束确需圆角的元素，U4 不得把它们改回圆角。
> 已同步写入 [`开发约定.md`](./开发约定.md) §6 第 5 条、[`开发进度.md`](./开发进度.md) §4 红线第 11 条。

**规定（写进 `docs/开发进度.md` §4 红线第 11 条、`docs/开发约定.md`）：**

1. 图标、卡片、面板、按钮、输入框、弹窗、牌面裁切等**一切圆角**必须使用**连续曲率**圆角（squircle / 超椭圆），
   **禁止**使用 `border-radius: Npx` 这种「直线 + 圆弧」的普通圆角（直线与圆弧交界处曲率突变）。
2. 统一资源：`apps/web/assets/squircle.svg`（超椭圆指数 `n=5`，归一化 `viewBox="0 0 1 1"`，
   `preserveAspectRatio="none"`，可由 `mask-size: 100% 100%` 拉伸到任意元素）。
   生成脚本：`review-assets/boot-preview/gen-squircle.py`（本轮为图标生成，后续可提升为正式脚本）。
3. 标准写法（同一目录的样式表）：

   ```css
   .surface {
     -webkit-mask-image: url("../assets/squircle.svg");
             mask-image: url("../assets/squircle.svg");
     -webkit-mask-size: 100% 100%;
             mask-size: 100% 100%;
     -webkit-mask-repeat: no-repeat;
             mask-repeat: no-repeat;
   }
   ```

   全局 token 已在 `styles/tokens.css` 的 `:root` 定义 `--ui-squircle`；
   跨目录使用时注意 CSS 相对 `url()` 以样式表位置解析，必要时写绝对路径或在使用处重新声明。
4. **滤镜与遮罩的顺序**：`filter` 先于 `mask` 生效，`mask` 会裁掉元素自身 `filter` 产生的投影。
   需要投影时把 `drop-shadow` 上移到父容器（本轮大厅牌已按此处理）。
5. **验收**：带圆角的新 UI 角部截图放大后不得出现曲率突变点；不得出现方角白色像素。
   `npm run verify:ui` 已有「U1 数据卡片直角」静态断言（检查右栏面板无 squircle mask、`border-radius = 0`、保留 1px 边框）；
   U2~U4 若新增带圆角面板，另补「使用 squircle 遮罩」静态断言。
6. **已落地**：exe 图标（`icon.ico` / `icon.png`）、大厅巨型牌 `.lobby-deck__card`。
   **待推广**：`#top-bar` 胶囊、`.lobby-panel`、`.btn`、`.card`、弹窗、结算卡等全部现有圆角元素
   —— 作为 U4 的一部分逐步替换，不在本轮改动；**右栏数据卡片按用户拍板保持直角，不列入推广清单**。
