## 2. 红线与硬约定

1. **摸牌**：主动摸牌点一次逐张摸，摸到可出为止；只能打刚摸的牌或结束回合。效果摸牌可一次多张。
2. **UNO**：单击立即喊，无二次确认；窗口 4 秒 + 倒计时条；最后一张出完直接赢，罚 2 张。
3. **UNO 窗口按钮**：窗口主人只见 `CALL_UNO`，其他座位只见 `CATCH_UNO`。
4. **结算**：无分数 / 趣味分 / 算分；只保留结算与操作统计图表；本地战绩仅 `games/wins`。
5. **挑战展示**：仅人类挑战 AI 时展示对方手牌；AI 挑战人类只提示，不泄露牌面。
6. **视图隔离**：`drawnThisTurn` 只发摸牌者；他人 `DRAW` 事件 `cards=[]`；联机按座位脱敏。
7. **联机**：服务端权威；客户端只消费自己的视图；`config.humanSeat=-1` 时必须用视角座位判断「我」。
8. **不做**：M6-03 台词人设库、M6-04 战绩统计页、表情自定义/持久化/文字聊天、联机智谱在线决策、对局快照（P2）。

## 4. 已知限制

- 智谱单次决策约 3.8s，可切本地 AI 规避；设置页规则只对新开对局生效。
- `wild4Legality` 仅引擎配置与单测覆盖，未上设置页。
- 刷新页面仍会中断对局；联机房间只在服务进程内存，服务重启即失效。
- 联机 AI 固定本地启发式，智谱在线决策未接入。
- 表情仅纯 emoji，无自定义、持久化、文字聊天；单机隐藏入口。
- 启动脚本不自动提权；局域网首次若防火墙未放行，需右键以管理员身份运行一次。
- 主机退出通知只在正常关窗路径发送；强杀/断电时客户端重连 3 次后回大厅。
- UDP 发现仅同网段大厅房间；防火墙/AP 隔离时手动 `IP:端口` 兜底。
- 桌面版自填 Key 的 DPAPI 边界是「防其他 Windows 用户」；同账户恶意程序仍可能解密。
- NSIS 安装包未签名；安装/卸载/启动/双机联机尚未在真实 GUI 验收。
- `verify:ui` 约 5 分钟、端口 9333；`verify:online` 端口 9334；`verify:desktop` 沙箱 SKIP 不算通过。
- 跨网公网联机（M11/M12）暂缓；当前不提供公网固定网址。
