## 2. 红线与硬约定（后续开发者请勿改回）

1. **摸牌**：主动摸牌**点一次摸一张，摸到能打出的牌才停**（2026-10-19 用户反馈）；而 +2/+4 效果摸牌、UNO 罚款等「效果摸牌」仍可一次多张，DRAW 事件带 `count`。
2. **UNO**：单击一次立即喊出（无二次确认弹窗）；UNO 窗口 **4 秒** + 按钮底部倒计时条。
3. **AI 思考延迟随机化**：约 0.8~1.7 倍抖动、下限 300ms；智谱「思考中」最短展示 500ms；智谱决策在动画播放期间预取。
4. **结算无任何分数 / 趣味分 / 算分口径**：结算页只保留最终结算 + 操作统计图表；本地战绩只写 `uno:stats` 的 games/wins。
5. **挑战手牌展示仅当挑战者是人类时可见**（AI 挑战人类只提示，不展示牌面）。
6. **动效 / 音效可关闭**；关闭动画或 reduced-motion 时不创建任何动效元素。
7. **大厅无用户名输入**（人类固定「你」）。
8. **M6-03 台词库 / 人设、M6-04 战绩统计**：用户明确指示不做；**M6-06 对局快照恢复**：暂不做（P2）。

### 4.3 M8 联机可用性修复（2026-10-19 用户实测反馈）

- **根因 1（连错服务器）**：房间只存在单台服务器进程内存里；两台电脑各自启动服务后，B 电脑浏览器开的是自己电脑的 `localhost:3000`，房间码当然查不到。修复：服务启动日志打印局域网地址（`net/lan.ts`）；`/api/health` 新增 `lanUrls`；房主房间面板显示「其他设备请打开 http://192.168.x.x:3000 并输入房间码 XXXX 加入」；`ROOM_NOT_FOUND` 文案说明连错服务器情形。
- **根因 2（防火墙）**：本机已有的 Node.js 放行规则只覆盖「公用网络」配置档，家庭 WiFi（专用网络）下入站 3000 被拦。修复：`启动服务.bat` 启动时自动添加全配置档放行规则 `UNO-Local-3000`（需管理员，无权限时打印指引）。
- **bat 修复**：先释放 3000 端口（重复双击/上次未退出导致的「端口被占用」假死）；改用 `npm start`（非 watch）；3 秒后自动打开浏览器；错误不再闪退（结尾 pause）。

### 5.5 M9-03 联机预置表情 ✅（2026-10-20）
- **协议**：`protocol.ts` 新增客户端 `emote {emoji}` 与服务端 `emote {seat, emoji}`；12 个纯 emoji 白名单（`EMOTE_EMOJIS`），非白名单消息按 `BAD_MESSAGE` 拒绝。
- **服务端限频**：`RoomManager.recordEmote` 按座位计数，一次性最多 5 条；发出第 5 条后进入 2 秒冷却（`EMOTE_BURST=5`、`EMOTE_COOLDOWN_MS=2000`），冷却期内返回 `EMOTE_RATE_LIMITED`。大厅离开导致座位重排时清空限频状态，开局/再来一局也重置。
- **广播**：`wsServer` 校验连接已进房后，向房间内所有连接广播发送者真实座位与 emoji；发送者自己也收到回显。
