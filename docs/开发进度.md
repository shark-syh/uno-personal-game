## 4. 红线与硬约定

1. **摸牌**：主动摸牌点一次逐张摸，摸到可出为止；只能打刚摸的牌或结束回合；效果摸牌可一次多张。
2. **UNO**：单击立即喊，无二次确认；最后一张出完直接赢，罚 2 张。UNO 窗口按难度 **10/8/6/4 秒**（休闲/简单/真实/骨灰级）；当前生产仍为固定 4 秒，M5 实施。M1 结论：时长用于 UI 环与单机推进节奏，窗口裁决仍在引擎/服务端，不新增超时罚牌。
3. **UNO 窗口按钮**：窗口主人只见 `CALL_UNO`，其他座位只见 `CATCH_UNO`。
4. **结算**：无分数 / 趣味分 / 算分；只保留结算与操作统计图表；本地战绩仅 `games/wins`。
5. **挑战展示**：仅人类挑战 AI 时展示对方手牌；AI 挑战人类只提示，不泄露牌面。
6. **视图隔离**：`drawnThisTurn` 只发摸牌者；他人 `DRAW` 事件 `cards=[]`；联机按座位脱敏。
7. **联机**：服务端权威；客户端只消费自己的视图；`config.humanSeat=-1` 时必须用视角座位判断「我」。
8. **UI 契约**：`window.UnoApp` 五个 API 与 DOM 锚点只增不改；出牌只点击手牌。
9. **v2 边界**：不改 `packages/game-core`、`packages/ai`、GameView/UiAction/事件类型、WebSocket 协议与桌面壳。
10. **不做**：M6-03 台词库、M6-04 战绩页、表情自定义/持久化/文字聊天、联机智谱决策、对局快照、M11/M12 跨网公网。

## 5. 已知限制

- 智谱单次决策约 3.8s；规则设置只对新开对局生效；`wild4Legality` 仍在引擎配置层。
- 刷新中断单机对局；联机房间在服务进程内存，重启即失效。
- 联机 AI 固定本地启发式；表情仅纯 emoji。
- 启动脚本不自动提权；局域网首次可能需管理员放行防火墙。
- 主机强杀/断电不发 `server-closing`；UDP 仅同网段；桌面 Key 的 DPAPI 只防其他 Windows 用户。
- NSIS 未签名；真实 GUI/安装/双机联机的真机验收已取消（2026-10-26 用户指令，安装包在 Release 供自取）。
- `verify:ui` 约 5 分钟；`verify:online` / `verify:desktop` 端口与沙箱限制见交接文档。
