## 3. 引擎/AI/UI 关键约定（违反会回归）

- 纯函数 reducer `applyAction(state, action) → { state, events }`（内部 structuredClone）；`state.events` 只本次、`state.history` 全量；seed 可复现；全牌恒 108 张。
- 堆方向：`drawPile` / `discardPile` **数组末尾是堆顶**（抽牌用 `pop()`）。
- 相位：`await-play` / `choose-color` / `stack-response` / `challenge-decide` / `uno-window` / `round-end`；`getLegalActions` 只给当前玩家。
- 摸牌（2026-10-17 用户规则）：DRAW 循环摸到 `isPlayable` 为止；`drawTo` 支持 `until` / `deferRoundEnd`；牌堆耗尽按 4.9 结算（不 advanceTurn）；事件顺序 …PILE_RESHUFFLE → DRAW → ROUND_END。
- 叠牌（loose）：+2/+4 任意互叠；单张 +4 链弃权 → `challenge-decide`；链中 +4 不开放挑战；最后一张 +2/+4 立即获胜（下家仪式性摸牌）。
- UNO：`uno-window` + `unoWindow.pendingPhase`；除 CALL/CATCH 外任何动作先关窗口；AI 喊/抓概率按 `aiDifficulty`；2.5s 窗口（`?test=1` 120ms）。
- 牌堆耗尽：默认 `reshuffle`，`end-by-fewest` 可配；并列最少 → 平局。
- 结算：`getResult(state, { durationMs })`，仅 `phase==='round-end'` 可调用；**统计全部由 history 汇总，不做分数**。
- **`packages/game-core/src/public-view.ts` 是 UI 唯一数据出口**（getGameView/toUiAction/toEngineAction/toPublicResult/createLobbyView），隐藏信息过滤都在这里；UI 不写规则。
- **挑战时手牌展示（M5-01）**：`CHALLENGE_SUCCESS` 仅当挑战者是人类时携带被挑战者手牌；UI 由 `js/ui/challengeReveal.js` 在 `#challenge-reveal` 展示 2.6s（期间 `aria-busy` 输入锁）；AI 挑战人类只 toast「XX 查看了你的手牌」，不展示牌面。
- **摸牌事件顺序（M5-03 修正）**：所有摸牌路径（主动摸牌 / +2/+4 效果 / UNO 罚款 / 挑战罚牌）统一为 `…PILE_RESHUFFLE → DRAW(count) → ROUND_END`（`drawTo` 先聚合 DRAW 再结算牌堆耗尽）。
- **规则设置（M5-06）**：`uno:settings` 新增 `twoPlayerRules`(true) / `unoPenalty`(2) / `deckExhaustion`("reshuffle") / `startCardRule`("classic")，仅对新开对局生效；`?test=1` 下引擎注入 `window.__unoEngineConfig` 供浏览器自动化断言最终 GameConfig（正常入口不写入）。
- **事件动效（M6-01）**：所有动效由 `animation/queue.js` 串行驱动，`js/animation/effects.js` 只创建临时节点（`#effect-layer`）并返回时长；队列结束/被打断/屏幕切换时 `cleanupEffects()` 兜底清理。设置页「动画速度」正常/快速，`?slow=1` 调试 ×2.2；`animation=false` 或 reduced-motion 时不创建任何动效元素。
- **音效（M6-02）**：`js/audio/sfx.js` 用 WebAudio 现场合成（无外部音频素材）；首次 pointerdown/keydown 创建并 resume AudioContext（autoplay 限制）；`sound=false` 时不创建 AudioContext；`soundVolume` 0~1，设置页低/中/高；自动化用 `data-audio`/`data-sfx-count` 观测。
- **智谱决策预取（M6 复验）**：`engineMode` 在每步结算后立即为"下一位是 AI"的局面发起智谱决策（`startPrefetch`），动画播放期间并行等待网络；用 `{seat, actionCount}` 校验局面，局面变化自动作废。智谱成功时「思考中」至少展示 500ms；`aiLatencyMs` 只用于状态栏 title，不进入契约必需字段。
- **本地战绩（M6 复验）**：每局结束只写一次 `uno:stats`（games/wins，平局计对局不计胜场），**禁止引入任何分数/算分口径**；`statsRecorded` 标记防止重复计数。大厅已移除用户名输入（人类固定「你」，`START_GAME.config.playerName` 字段仍兼容）。
- 浏览器前端零构建：TS 引擎+AI 用 esbuild 打包为 `apps/web/js/vendor/uno-engine.js`；**改 packages 后必须 `npm run build:web-engine`**，`apps/server/tests/web-engine-bundle.test.ts` 会校验同步。
- 默认入口 = 引擎模式真实对局（`?mock=1` mock、`?test=1` 快速）；大厅选项（人数/难度/玩家名/+4 挑战/AI 模式）→ `GameConfig`。
- 设置：`localStorage` 键 `uno:settings`（autoCallUno/aiSpeed/sound/animation/showHint/aiChatter）、`uno:stats`（仅 games/wins，bestScore 已删除）。
- 自对弈：`npm run selfplay` 700 局；新规则后平均回合约 60~160（实测 92），判定容差 2%（强档胜率 ≥48%）+ 混战名次差 0.15；大样本（seed m3-edge，1500 局）真实 vs 骨灰级 54.4%。
