## 7. 关键坑位

- `unoWindow.canCatch` 语义是「可被抓的目标」（开窗时 = 窗口主人），不是抓人者名单。
- 联机 `config.humanSeat = -1`；单机为 0。判断「我」必须用视角座位，不能写死 0。
- 联机每个座位 `isHuman` 可能为 true，对手框要用 `seat !== viewer` 过滤，不能靠 `!isHuman`。
- `drawnThisTurn` 只在 `state.currentSeat === seat` 时下发；他人 DRAW 事件 `cards=[]`。
- 开局座位随机；起手 Skip/Reverse/+2 由首位玩家承受，手牌可能 >7，断言别写死 7。
- vitest 默认超时 5000ms；WS 集成测试内部等待超过 5s 必须显式传 `{ timeout }`。
- `verify:ui` 端口 9333，`verify:online` 端口 9334；后台标签页定时器可能被节流，冷却断言用轮询。
- 局域网房间只在服务进程内存；IP 变化以 `/api/health` 为准；防火墙规则 `UNO-Local-3000`。
- 启动脚本不要写 PowerShell 自提权/隐藏窗口：已被火绒误报为 `PS.NetLoader`。保持纯 cmd。
- 卡面解码偶发时序 flaky（verify:ui 102/103），复跑即可；不要因此改业务代码。
