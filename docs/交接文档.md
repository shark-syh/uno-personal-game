## 7. 关键坑位

- **座位与视图**：`unoWindow.canCatch` 是「可被抓的目标」（开窗时 = 窗口主人），不是抓人者名单；联机 `config.humanSeat=-1`、单机为 0，判断「我」必须用视角座位；联机每个座位 `isHuman` 可能为 true，对手框用 `seat !== viewer` 过滤；`drawnThisTurn` 只在 `state.currentSeat === seat` 时下发，他人 DRAW 事件 `cards=[]`。
- **开局/测试**：开局座位随机，起手 Skip/Reverse/+2 由首位玩家承受，手牌可能 >7，断言别写死 7；vitest 默认超时 5000ms，WS 集成测试内部等待超过 5s 必须显式传 `{ timeout }`。
- **端口/flaky**：`verify:ui` 端口 9333，`verify:online` 端口 9334；后台标签页定时器可能被节流，冷却断言用轮询；卡面解码偶发 106/107，复跑即可，不要改业务代码。
- **局域网**：房间只在服务进程内存；IP 变化以 `/api/health` 为准；防火墙规则 `UNO-Local-3000`；UDP 发现固定 `41234`、2 秒广播、TTL 7 秒，只广播 `lobby`，开局后消失，同网段/防火墙/AP 隔离会影响发现，手动 `IP:端口` 兜底。
- **启动脚本**：不要写 PowerShell 自提权/隐藏窗口，已被火绒误报为 `PS.NetLoader`；保持纯 cmd。
- **桌面启动**：`main.ts` 必须先 `import './environment.ts'` 再导入 server；`listen(0)` 后 `/api/health` 必须用实际端口（`createUnoServer` 默认读 `server.address()`）。
- **Electron/NSIS**：Electron 二进制首次运行才下载，GitHub 直连 TLS 失败时用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后执行 `node node_modules/electron/install.js`；标准 electron-builder NSIS 会执行中间安装器，本项目改为 `nsis.script: installer.nsi` + 原生 `WriteUninstaller`，打包只跑 `makensis`，不要删掉；`electron` 必须写精确版本 `44.9.1`，打包设 `ELECTRON_MIRROR` / `ELECTRON_BUILDER_BINARIES_MIRROR`。
- **打包产物**：`apps/desktop/release/` 已 gitignore；`apps/desktop/build/`（图标 + `installer.nsi`）要入库；`release/win-unpacked` 可能是旧目录，验收以安装包为准。
- **Key 安全**：`safeStorage` 只能在 `app.whenReady()` 之后使用；`bootstrap()` 先 `loadStoredApiKey()` 再 `startUnoServer()`；运行时来源统一走 `apps/server/src/ai-key.ts`（自填 > `.env`），`zhipuClient.isConfigured` 必须是 getter；Key 只经 `window.unoDesktop.aiKey` 状态/保存/清除进出，IPC 永不回传明文，不写进 `/api/config`、日志或 DOM。
- **桌面 UI 分流**：`verify:ui` 在浏览器模式断言设置页不显示桌面 Key 区域；桌面专属 UI（Key、手动主机、附近房间）一律用 `window.unoDesktop` 分流。
- **远程加入**：目标主机必须写入 `joined.host`（`host:port`），断线重连和刷新恢复都依赖它；发现结果只经 `uno:discovery-list/find` 只读 IPC 返回，`findRoom` 先匹配本机内嵌房间再查 UDP 缓存，同码多个兼容主机才显示选择器；`listRooms` 轮询失败必须静默，`window.unoDesktop.discovery` 不存在时新入口隐藏。
- **房主迁移**：只由服务端 `RoomManager.promoteHost()` 决定；房主断线/离开→下一位在线玩家；原房主重连不夺回；全员断线时保留原房主。
- **关服/重连**：`server-closing` 是只增消息；桌面 `stopUnoServer()` 必须先 `notifyShutdown()` 并等约 150ms 再断开；强杀进程不会走该路径；客户端 WS 握手超时 8 秒，旧 socket 的 handler 必须用 `socket === ws` 守卫。
- **沙箱限制**：真实 Electron GUI 会以 `0x80000003` / `0xC0000005` 退出，桌面窗口验收需用户桌面会话；`verify:desktop` 在沙箱输出 SKIP，不要当成通过；真机可设 `UNO_REQUIRE_DESKTOP=1` 强制失败退出。
