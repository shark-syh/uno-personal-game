## 7. 关键坑位

- **座位与视图**：`unoWindow.canCatch` 是「可被抓的目标」，不是抓人者名单；联机 `config.humanSeat=-1`、单机为 0，判断「我」必须用视角座位；对手框用 `seat !== viewer` 过滤；`drawnThisTurn` 只在 `state.currentSeat === seat` 时下发。
- **开局/测试**：开局座位随机，起手 Skip/Reverse/+2 由首位玩家承受，手牌可能 >7，别断言写死 7；WS 集成测试等待超过 5s 必须显式传 `{ timeout }`。
- **端口/flaky**：`verify:ui` 9333、`verify:online` 9334；后台标签页定时器可能节流，冷却断言用轮询；卡面解码偶发 106/107，复跑即可。
- **局域网**：房间只在服务进程内存；IP 以 `/api/health` 为准；防火墙规则 `UNO-Local-3000`；UDP 固定 `41234`、2 秒广播、TTL 7 秒、只广播 `lobby`，开局后消失；手动 `IP:端口` 兜底。
- **启动脚本**：不要写 PowerShell 自提权/隐藏窗口，会被火绒误报 `PS.NetLoader`；保持纯 cmd。
- **桌面启动/分流**：`main.ts` 必须先 `import './environment.ts'` 再导入 server；`listen(0)` 后 `/api/health` 必须用实际端口；桌面专属 UI 一律用 `window.unoDesktop` 分流，`verify:ui` 在浏览器模式断言不显示桌面 Key 区域。
- **Electron/NSIS/打包**：Electron 首次运行才下载，失败用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后执行 `node node_modules/electron/install.js`；用 `nsis.script: installer.nsi` + 原生 `WriteUninstaller`，打包只跑 `makensis`；`electron` 精确版本 `44.9.1`；`release/` 已 gitignore、`build/`（图标 + `installer.nsi`）入库，验收以安装包为准。
- **Key 安全**：`safeStorage` 只能在 `app.whenReady()` 后用；先 `loadStoredApiKey()` 再 `startUnoServer()`；来源统一走 `apps/server/src/ai-key.ts`；`zhipuClient.isConfigured` 必须是 getter；IPC 永不回传明文。
- **远程加入/房主/关服**：`joined.host` 必须写 `host:port`；发现结果只经 `uno:discovery-list/find` 只读 IPC；`listRooms` 轮询失败静默；房主迁移只由 `RoomManager.promoteHost()` 决定，原房主重连不夺回；`server-closing` 只增消息，`stopUnoServer()` 先 `notifyShutdown()` 等约 150ms，WS 握手 8 秒，旧 socket 用 `socket === ws` 守卫。
- **沙箱限制**：真实 Electron GUI 会以 `0x80000003` / `0xC0000005` 退出；`verify:desktop` 沙箱 SKIP 不是通过；真机可设 `UNO_REQUIRE_DESKTOP=1`。
- **M13**：卡背只读 `handCount`，`data-hand-count` / `data-visible` / `data-layout` 是稳定契约；420 隐藏卡背但保留精确牌数。
