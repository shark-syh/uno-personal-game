# UNO Local · 关键接口与架构（v2.2.0）

> 面向接手者的唯一浓缩入口：只保留接口契约、分层与数据流，不含开发过程、方案讨论、验收历史。
> 版本 v2.2.0（2026-11-09 已发布，commit `af68d67`）；原 21 份过程文档仍留在本仓库 `docs/`，本压缩包不附带。

## 1. 项目身份与边界

- 单机：1 名真人 + 2~9 名四档 AI（休闲 / 简单 / 真实 / 骨灰级），智谱 GLM 混合决策（失败自动降级本地 AI）。
- 联机：局域网房间码，服务端权威、AI 补位、断线重连、房主移交；无跨网公网。
- 技术栈：浏览器原生 ES Modules + CSS（无框架）；规则引擎 TypeScript → 打包成 `apps/web/js/vendor/uno-engine.js` 供浏览器直接 import；服务端 Express 5 + `ws`；桌面 Electron 44.9.1 + NSIS。
- **v2 硬边界**：不改 `packages/game-core`、`packages/ai`、`GameView` / `UiAction` / 事件类型、WebSocket 协议、桌面壳。前端 DOM 锚点一律「只增不改」。

## 3. 两条主数据链

```text
单机：app.js → engineMode.js → vendor/uno-engine.js (applyAction)
      → getGameView(state, …) → window.UnoApp.render(view) → ui/render.js → 各屏 UI
      → UnoApp.playEvents(events, done) 串行播动效（期间 aria-busy 输入锁）

联机：客户端 /ws → wsServer.ts（服务端权威状态机）→ sanitizeEventsForSeat 按座位脱敏
      → {type:'view'} → onlineMode.js 视图队列 → UnoApp.render → 同上

智谱：浏览器 POST /api/ai/decide（公开信息 + 自己手牌 + 候选动作）
      → 服务端代理 GLM → 校验 actionId 落在候选内 → 失败降级本地 AI
```

- **关键坑**：引擎 `applyAction` 每次动作都把 `state.events` 重置为本批次；折线图等需要全量时间线的功能在 UI 层累积 `eventHistory`（单机 `rt.eventHistory`、联机模块级 `eventHistory`，遇 `DEAL` 重置）。
- **视图隔离**：`drawnThisTurn` 只发摸牌者；他人 `DRAW` 事件 `cards=[]`；`config.humanSeat=-1` 时用视角座位判断「我」。
- **UNO 窗口**：10/8/6/4 秒由引擎 / 服务端裁决，按钮与金环只改 UI，到期不提交动作。

## 4. 关键接口

### 4.1 `window.UnoApp`（5 个 API，只增不改）

| API | 说明 |
| --- | --- |
| `render(view)` | 渲染一份 `GameView`；`view.mock` 决定 mock / engine 模式 |
| `playEvents(events, done)` | 串行播放事件动效，完成后回调；动画关闭 / reduced-motion 立即完成 |
| `setActionHandler(fn)` | 注入动作回调（`UiAction` → 模式层）；联机由 `onlineMode` 注入 |
| `setMockMode(enabled, name='lobby')` | 切换演示局面 / 回到真实引擎 |
| `getMode()` | 返回 `'engine'` / `'mock'` |

### 4.2 DOM 锚点（摘关键，完整见 `index.html`）

- 屏：`#lobby-screen`、`#game-screen`、`#result-screen`、`#app`、`#boot-screen`
- 大厅：`#lobby-form`、`#lobby-start`、`#player-count-options`、`#difficulty-options`、`#ai-mode-options`、`#challenge-wild4`、`#online-block`、`#room-panel`
- 对局：`#top-bar`、`#game-meta`、`#game-grid`、`.phase-rail`、`#table-area.arena`、`.right-rail`、`#opponents`、`#table-center`、`#draw-pile`、`#discard-pile`、`#event-feed`、`#speech-layer`、`#phase-banner`、`#effect-layer`
- 手牌 / 动作：`#hand-zone.player-zone`、`.hand-deck`、`.hand-rail`、`#hand`、`#action-bar.action-stack`、`#hint-bar`
- 右栏数据：`#rail-turn-no`、`#rail-turn-chip-no`、`.status-card` ×2（6 个 `.status-line`）、`#hand-trend`、`#hand-trend-legend`
- 结算：`#result-content`（运行时生成 `.result-top` / `.result-body` / `#result-title` / `#result-charts`）
- 通用：`#dialog-root`、`#toast-region`、`#emote-picker`、`#dev-toolbar`

### 4.3 引擎 / 视图契约（`packages/game-core/src/public-view.ts`）

- `GameView`：`mock`、`screen('lobby'|'game'|'result')`、`phase(GamePhase)`、`config`、`currentSeat`、`direction`、`currentColor`、`players[]`、`human`、`table`、`events[]`、`result`、`settings`、`dev`、`runtimeAiMode?`、`aiModel?`。
- `UiAction`：`{ id, type, label, cardId?, colorChoice?, color?, hint? }`；配套 `toUiAction()` / `toEngineAction()` / `getHumanLegalActions()`。
- `applyAction(state, action) → ApplyActionResult`；`getLegalActions()`；`isGameOver()`；`getResult(state,{durationMs})`。
- `GamePhase`：`lobby / dealing / turn-start / await-play / choose-color / stack-response / challenge-decide / uno-window / turn-end / round-end`。
- `GameEvent`（联合类型，完整见 `types.ts`）：`DEAL / START_CARD / PLAY / COLOR_SET / SKIP / REVERSE / DRAW / PILE_RESHUFFLE / PLAYER_OUT / ROUND_END / STACK_PUSH / STACK_RESOLVE / …`（UNO、挑战类同）。
- AI：`decide(view)`、`generateCandidates()`、四档 `DifficultyProfile`。

### 4.4 HTTP（Express，默认 `http://localhost:3000`；桌面版随机端口）

| 接口 | 返回 / 用途 |
| --- | --- |
| `GET /api/health` | `{status, service, version:'2.2.0', uptimeSec, time, lanUrls[]}`；前端品牌版本号唯一来源 |
| `GET /api/config` | `{aiEnabled, model, fallbackModels, hasWebUi, aiDecisionImplemented, aiTimeoutMs}`；**不返回 Key** |
| `POST /api/ai/decide` | 候选动作 → GLM → `{ok, actionId, reason, line, model, latencyMs}` |
| `POST /api/ai/test` | 设置页测试连接 |
| `GET /` | 静态托管 `apps/web/` |

### 4.5 WebSocket `/ws`（`apps/server/src/net/protocol.ts`）

- 客户端 → 服务端：`create-room`、`join-room`、`start-game`、`action`、`leave-room`、`rename`、`rematch`、`rejoin`、`emote`。
- 服务端 → 客户端：`joined`、`room`（房间快照）、`view`（按座位脱敏 `GameView`）、`emote`、`error`、`server-closing`。
- 服务端权威：客户端只提交 `EngineAction`，不自行推演状态；上行动作在视图队列播放期间被拒。

### 4.6 本地存储

`localStorage['uno:settings']`（动画 / 音效 / AI 速度 / 规则 / showHint）、`localStorage['uno:stats']`（仅 `games` / `wins`，不算分）、`sessionStorage['uno:bootPlayed']`、`uno:lobbyIndex`、`uno:online`（重连会话）。

## 6. 红线（最小集合）

1. 出牌**只点手牌**；空格等价于点击主操作按钮，不代劳出牌；Tab → Enter 出牌路径保留。
2. 牌面素材不可修改，白角只在显示层用遮罩处理；一切确需圆角 UI 用连续曲率 `--ui-squircle`，**数据显示卡片直角**（`.status-card` / `.rail-turn-chip`）。
3. 右栏 U1 六项字段与回合数一个不丢；≤1080 收为 168px 紧凑摘要（不隐藏）；三块面板间距 ≥8px。
4. 触控目标 ≥44px；`prefers-reduced-motion` / 动画关闭时新增装饰无动画名、无过渡。
5. 视图隔离与联机脱敏（见 §3）；无算分、无台词库 / 文字聊天 / 对局快照 / 跨网公网联机。
6. DOM 锚点与 `window.UnoApp` 五个 API 只增不改；既有验收断言不得放宽、改名或删阈值。
7. 流程：未说「开始 Mx/Ux」不开工；每模块完成即停；汇报只三段；改完必须实跑自检；批准后先 commit + tag 再开工（默认不 push）。
