## 4. 关键坑位（M8 踩过，勿再踩）

- **引擎 `unoWindow.canCatch` 语义 = 「可被抓的目标」**（开窗时 = [窗口主人]），不是抓人者名单；权限判断要按「窗口开着 + 不是自己 + 目标是窗口主人」。
- **联机 `state.config.humanSeat = -1`**：联机没有单一人类座位，置 -1 后引擎开窗 canCatch=[窗口主人]，任何其他人都能抓（含 0 号位）。
- **视图隔离**：`getGameView` 的 `drawnThisTurn` 只发摸牌者本人（`state.currentSeat === seat` 才带）；他人摸牌走 `sanitizeEventsForSeat`（DRAW 事件 cards=[]）。
- **窗口动作按座位过滤**（M9-01）：`getHumanLegalActions` 在 uno-window 阶段——CALL_UNO 只给窗口主人，CATCH_UNO 只给其他人。
- **引擎起手 Skip/Reverse/+2 由首位玩家承受**：开局手牌可能 >7，断言别写死「=7」（已修 4 处）。
- **vitest 默认测试超时 5000ms**：WS 集成测试内部等待超 5s 时必须显式加 `{ timeout }`，否则真实错误被掩盖。
- **开局座位随机**：测试别假设房主 0 号位固定先手。
- **局域网排障**：房间只在开服务那台机器内存；防火墙入站规则 `UNO-Local-3000`（需管理员，bat 会自动加）；本机 IP 会变（WiFi/热点切换），以 `/api/health` 的 `lanUrls` 实时值为准。
- **联机 AI 固定本地启发式**：智谱在线决策未接入联机（待用户确认是否补做）。
