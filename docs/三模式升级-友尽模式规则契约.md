## 1. 牌堆：168 张 / 68 个唯一面

以 `shared/engine/deck.ts`（注释标明 Mattel HWV18 盒装）与 Fandom / Wikibooks 牌表为准：

| 类别 | 组成 | 张数 |
| --- | --- | --- |
| 数字牌 | 0~9 各色 **2 张** × 4 色 | 80 |
| 彩色功能牌 | Skip / Reverse / Draw 2 / Discard All 各色 **3 张** × 4 色 | 48 |
| 彩色功能牌 | Draw 4 / Skip Everyone 各色 **2 张** × 4 色 | 16 |
| 万能牌 | Wild Reverse Draw 4 ×8、Wild Color Roulette ×8、Wild Draw 6 ×4、Wild Draw 10 ×4 | 24 |
| **合计** | | **168** |

**注意一处文档矛盾**：`RULES-REFERENCE.md` 第 156 行概述写「标准 Wild 与 Wild Draw Four 仍在牌堆中」，但盒装牌表、`deck.ts` 注释（"no plain Wild"）、Fandom 与 Wikibooks 均明确 **No Mercy 没有普通 Wild / Wild +4**，由四类新万能牌取代。实现按后者（待用户确认口径）。这也意味着项目现有的 `wild4` 挑战逻辑在友尽模式不适用。

## 2. 四条专属规则（核心）

1. **抽到能出为止（Draw to Match）**：无牌可出时必须**持续逐张抽**，直到抽到可出的牌，并**立即打出**；不是基础版「摸 1 张就能结束回合」。这一条与项目 §4 红线 1「主动摸牌逐张、摸到可出为止」**天然一致**。
2. **罚牌叠加（Stacking）**：被 +2 / +4 / +6 / +10 / Wild 反转+4 指向时，可打出**等值或更高罚牌**把累计总额推给下家；只有罚牌能叠，Skip / Reverse 不能叠；第一个接不住的人抽走累计总额并被跳过。+10 是叠链上限（可等值传递但不会再变大）。
3. **7 换手**：打出任意颜色 7 → 与任意一位玩家**交换整副手牌**（强制，官方无「不换」选项）。
4. **0 传手**：打出任意颜色 0 → 全体按**当前出牌方向**把手牌传给下一位。
5. **Mercy 淘汰**：任何时刻手牌 **≥25 张**立即出局；手牌搁置，待牌堆耗尽重洗弃牌堆时放回；出局者不再行动、不参与 7 换手 / 0 传手。

## 3. 逐张卡牌效果

| 牌 | 效果 |
| --- | --- |
| 数字 1~9 | 无特殊效果，按颜色 / 数字匹配 |
| 0 | 全体按当前方向传手 |
| 7 | 与任意玩家交换整手牌 |
| Skip | 下家跳过一回合 |
| Reverse | 出牌方向反转；2 人局等同 Skip（自己再来） |
| Draw 2（+2） | 下家抽 2 并跳过；可参与叠链 |
| Draw 4（+4，彩色） | 下家抽 4 并跳过；可参与叠链 |
| Skip Everyone | 其余玩家全部跳过，自己立即再来一回合；**方向不变** |
| Discard All | 弃掉手中所有与该牌同色的牌，压在该牌下方；可一次清空直接获胜；不改变颜色 |
| Wild Draw 6（+6） | 出牌者指定续玩颜色，下家抽 6 并跳过；可叠链 |
| Wild Draw 10（+10） | 同上但抽 10；叠链上限 |
| Wild Reverse Draw 4 | 先反转方向 → 新方向的下家抽 4 并跳过 → 出牌者选色；**2 人局变成自己抽 4**（可立即叠罚牌回敬） |
| Wild Color Roulette | **下家**选色 → 逐张翻抽直到抽到该色（Wild 不计）→ 全部加入手牌并被跳过；该色成为续玩颜色；**不参与叠链** |
| 全部万能牌 | 任意时刻可出、**无「手里没有当前颜色牌」限制、不可被质疑**（官方 No Mercy 取消挑战规则） |

## 4. 回合、开局与胜负

- **开局**：每人 7 张，其余作抽牌堆，翻首张为弃牌堆。首张若是功能牌：官方说明书口径为「忽略并翻下一张直到数字牌」（Wikibooks 称 post-2018 规则），部分来源说起效 → **待拍板**。
- **出牌**：按颜色 / 数字 / 符号匹配；万能牌随时可出；每回合只出 1 张（Discard All 的额外弃牌是效果例外）。
- **UNO 喊**：剩 1 张时喊，被抓罚 2 张（与项目 §4 红线 2 一致）。
- **两种胜利**：① 出完所有手牌；② 其余玩家全部被淘汰，**最后幸存者**胜。
- **最后一牌**：若是罚牌，下家仍须抽牌并计入结算；若是 7 / 0，先判胜、换手 / 传手效果不再发生。
- **计分（官方可选）**：数字牌面值 / 彩色功能牌 20 分 / 万能牌 50 分 / 每淘汰一名 +250 分，先到 1000 分。**项目 §4 红线 4 是「无算分」→ 建议只做单局胜负，不引入计分**。

## 5. 二人局与边界情况

- Skip / Skip Everyone / Reverse 在 2 人局都等于「自己再来一回合」；Wild Reverse Draw 4 变成自罚 4，可用叠加回敬形成来回拉锯。
- 轮盘抽牌途中牌堆与弃牌堆同时耗尽：上游 `rouletteDrawStep` 返回 `'exhausted'`，需定义兜底（建议停止抽牌并跳过该回合）。
- 已淘汰座位不参与 7 换手 / 0 传手；0 传手只在**仍在局中的玩家**之间旋转。
- 抽牌堆耗尽时重洗弃牌堆，此时把淘汰者搁置的手牌一并放回。
- 常见村规（非官方）：允许质疑 +6/+10、叠 Skip/Reverse、Jump-In、UNO 罚 4 张、关闭 7-0 或 Mercy 规则 → 默认**不启用**。

## 6. 与项目现有引擎的映射（开发依据）

- **可直接复用**：叠牌链（`stack-response` 阶段、`startStack` / `playStackCard` / `resolveStackDraw`）、`draw2` / `wild4` 罚牌数值、`getLegalActions()` 单一动作源、`uno-window` 喊 UNO、按座位脱敏、单机/联机共用 `GameView` 与事件队列。
- **需新增**：12 种 `CardKind`（现有 6 种）、`createDeck(config)` 168 张牌表、7 换手 / 0 传手动作与事件、Mercy 淘汰状态与「最后幸存者」胜利判定、轮盘 / 全弃 / 全员跳过新增阶段与事件、联机 `rooms.ts` 透传 mode。
- **需关闭**：友尽模式不设 `challengeWild4`、`wild4Legality` 不适用、不含普通 Wild / Wild +4。
- **为什么先做友尽更顺**：卡面 68 唯一面现成、规则长文 + 可执行引擎现成、纯规则变化（无双面牌 / 翻面 / 暗面四色 / 500 分制）、红线 1 与「抽到能出为止」天然吻合，UI 交互层几乎零改动；相比之下 Flip 还要先补第三套卡面并改 GameState 结构。

## 7. 口径定稿与待确认

> **M1（2026-11-13）已按下列建议默认值实现数据层**：牌表取官方盒装（无普通 Wild / Wild +4）、开局首张功能牌忽略重翻、只做单局胜负不算分、7 换手强制、B 版卡面不随公开渠道外传。叠链 `official` 口径与「友尽模式关掉 +4 挑战」留到 M2 落地。以下默认值用户确认前可调整，不影响基础模式。

1. 牌表口径：官方盒装（无普通 Wild / Wild +4）vs `RULES-REFERENCE.md` 概述（保留）——**M1 采用前者**。
2. 开局首张功能牌：忽略翻下一张（建议）vs 立即生效。
3. 计分：只做单局胜负（建议，守红线 4）vs 引入 1000 分制（需破红线）。
4. 叠链：`official`（只能出 ≥ 上一张）vs 项目现有 `loose`（宽松）——建议友尽独立设 official，不动基础模式。
5. 7 换手是否允许「不换」（上游 Open Mercy 做成可选，官方为强制）——建议强制。
6. B 版卡面是否随 exe 分发（权限申明已限定为不随公开渠道外传）。
7. 模块编号（建议 M1 或 V1）与「开始 M1」指令。
